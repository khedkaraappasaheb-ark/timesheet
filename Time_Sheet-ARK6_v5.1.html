🧪 Demo data loaded — this sample month shows every status (Present, Weekend, Holiday, On Leave), a row with missing fields (red outline), calculated paid hours, and Daily Plan/Remarks drop-downs. Switching Month/Year loads that month's own sheet automatically (each of the 12 months keeps its own saved data), and pre-fills every date in the month.

Daily Log

Status defaults to "Weekend" (yellow) on your Weekend Days and "Present" on weekdays; change any day to Holiday, Present, or On Leave as needed. Paid Time is calculated automatically from First Arrival and Last Departure. Daily Plan and Remarks are drop-downs built from what you have already entered — pick "+ Add new…" for a new entry. After you fill a field, you can copy the same value to all remaining empty working days in one tap.

Export

The .xlsx keeps the yellow weekend/holiday highlighting and red missing-field outlines, plus the employee name and period at the top (and the company name too, if you filled it in). CSV is plain text with the same header rows but no colors.

Send to Manager

On a phone or tablet this opens your share sheet with the file attached — choose your email app. On a computer the file is downloaded and your email app opens with the message ready; attach the downloaded file before sending.

Security

Checking device biometric support…

App Lock protects this app on this device. Encrypted backups use AES-GCM with a password-derived key. The backup password is never stored in the app.

Backup & Restore

Your data is stored only in this browser. When backup encryption is enabled, the downloaded backup is password-protected and cannot be restored without that password. Older plain JSON backups remain restorable. Restoring replaces the data currently on this device.
